# Alexandru Mihailescu

Applied ML engineer working on computer vision and reinforcement learning, with a hardware background that goes all the way down: embedded firmware, control, mechanical design, and a 3D printer I rebuilt to make the parts.

MSc in Automation and Computer Engineering at the University of Padua, after a BSc in Biomedical Engineering and an industrial electronics diploma. Based in the Veneto, Italy.

## Projects

| Project | What it does | Headline result |
|---|---|---|
| [fine-grained-car-classification](https://github.com/artaeun/fine-grained-car-classification) | Five CNN architectures compared on CompCars, including a hierarchical multi-task classifier with shared backbone and dual heads | **87.55%** top-1 test accuracy, **4.65 points** over the OverFeat baseline |
| [weather-classification-svm](https://github.com/artaeun/weather-classification-svm) | Hand-engineered colour and Difference-of-Gaussian features, PCA, SVM. The fitted models ship, so it runs without the dataset | **96.04%** on MWD, and the descriptor transfers to ACDC at **90.6%** |
| [deep-rl-snake](https://github.com/artaeun/deep-rl-snake) | PPO agents on a custom Gymnasium Snake environment, under full and partial observability, with a reward-shaping ablation | **196%** over the heuristic baseline. The partially observable agent beats the fully observable one |
| [sunflower-solar-tracker](https://github.com/artaeun/sunflower-solar-tracker) | A two-axis solar tracker built from scratch: printed gearbox, custom electronics, firmware, and a gradient-ascent light-seeking controller | Tracks on both axes. Printed body, 638:1 first gearbox, and every failure documented |

Each repo carries a full technical report as a PDF.
